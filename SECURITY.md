# Security Policy

This repository contains security research materials. Please follow the policy below.

Reporting a Vulnerability
- Do not disclose vulnerabilities publicly. Open a private issue or contact the repository owner with reproduction steps and any mitigations.
- Provide minimal reproduction steps that avoid exposing sensitive data.

Supported Versions
- This research targets LifeCarePharmacy12 artifacts present in this repository only.

Acknowledgements
- We appreciate coordinated disclosure and will respond to reports in a timely manner.
