# Contributing

Thank you for taking an interest in improving this repository. This project contains security research artifacts and PoCs — please follow the rules below.

1. Issues and PRs
   - Open issues for bugs, errors, or documentation improvements. Do not post or attach sensitive data (passwords, PII, or secret keys).
   - Use pull requests to propose changes. Provide a clear summary and rationale.

2. Safe Testing
   - Do not run PoCs against third‑party or production systems. Use isolated, snapshot-backed labs.
   - When adding examples, ensure they use synthetic data or explicit mock/test fixtures.

3. Responsible Disclosure
   - If you find new vulnerabilities, follow responsible disclosure: notify vendor and maintain confidentiality until patched.

4. Code Style
   - Keep changes small and focused. Follow existing style in Python files.
